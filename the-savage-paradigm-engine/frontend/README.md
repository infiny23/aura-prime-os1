### Project Overview
- **Project Name**: The Savage Paradigm Engine - Full Code & System Schema
- **Version**: 8.0
- **Description**: A complete package containing the full system architecture, code, schematics, and operational blueprints for the Aura Prime and Project Void project.

### Architectural Summary
- The system evolves from a v7.1 serverless stack using Next.js, Vercel, and Gemini into the v8.0 'Archon Kernel', featuring a dual-kernel architecture with the 'Aura' Execution Kernel and the 'Void' Meta-Kernel.

### Key Components
1. **v7.1 Genesis Drive Codebase**:
   - **Manifest**: `package.json` for the Next.js-based kernel.
   - **Deployment Configuration**: `vercel.json` for cron job setup.
   - **Type Definitions**: `lib/types.ts` for data schemas.
   - **Core Logic**: Includes LLM gateway, arbitration engine, and meta-learning kernel.

2. **Application Layer**:
   - **Server Actions**: Functions for starting cycles and fetching system state.
   - **Cron Job**: Processes the job queue.
   - **Command Center UI**: Main UI component for interacting with the system.

3. **Simulation UI Codebase**:
   - **Manifest**: `package.json` for the Vite + React project.
   - **TypeScript Config**: `tsconfig.json` for TypeScript settings.
   - **Vite Config**: `vite.config.ts` for build configuration.
   - **UI Components**: Various React components for the AuraOS interface.

4. **System Diagrams**:
   - **Event-Driven Architecture**: Visual representation of the system's architecture.
   - **Adaptive Autogenesis Loop**: Diagram illustrating the cognitive processes.
   - **Coherence Threshold Unlocking**: Diagram showing cognitive potential states.
